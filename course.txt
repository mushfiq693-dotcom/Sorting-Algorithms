# AlgoHub — Course Material Feature & Content Generator Prompt
# (Lipschutz & Seymour, "Data Structures," Revised 4th Edition & Class Materials)

You are working on the existing **AlgoHub** project. Your task is to process new lecture topics, textbook algorithms, and assigned problems from *Lipschutz & Seymour, "Data Structures," 4th Edition* (provided via attached screenshot(s) or text) and integrate them seamlessly into AlgoHub's **Course Material** system.

---

## 🎯 Core Objectives & Strict Principles

1. **Self-Contained Content Generation**: Read and understand the attached screenshot(s)/text with high academic rigor and accuracy. Generate formal algorithm specifications, step-by-step traces, proofs, and comprehensive worked solutions.
2. **Deep, Exam-Focused Pedagogical Bengali Explanations (`bangla_explanation`)**: Every single topic, algorithm, and problem MUST include a comprehensive, deep, and structured Bengali guide specially crafted for students to score **Full Marks (100%)** in semester/university exams. Avoid scattered text, one-liners, or superficial summaries.
3. **Mandatory Exam Q&A & Model Answers**: Every `bangla_explanation` must include a dedicated **"🎯 পরীক্ষায় কেমন প্রশ্ন আসতে পারে?" (Probable Exam Questions)** section and a **"✍️ পরীক্ষার জন্য প্রস্তুতকৃত আদর্শ উত্তর" (Exam-Ready Model Answers)** section with point-by-point, full-marks-scoring responses.
4. **Interactive Visualizer Engines (Simulation Labs)**: When a topic or problem involves step-by-step execution, pointer manipulation, memory arrays, stack operations, or complexity comparisons, provide or connect an interactive React simulation studio in `src/components/course-material/`.
5. **Flawless Light & Dark Mode UI Consistency**: Every component, visualizer, code block, math formula card, and table must look stunning and highly readable in BOTH Light Mode and Dark Mode. Never hardcode dark-only background colors (`bg-slate-900`, `bg-black`, `#14100D`) without proper light mode styling (`bg-card`, `bg-muted`, `dark:bg-...`).
6. **Preserve Existing Codebase**: Do NOT rewrite or break existing sorting algorithms, authentication flows, database schemas, or unrelated views. Only update or extend the Course Material data and component layers.

## 1. Content Modeling & Data Structure

Course materials are stored in `src/data/defaultCourseMaterials.ts` (and synced to Supabase `course_materials` table):

```typescript
export type CourseMaterialContentType = "topic" | "problem" | "algorithm";
export type CourseMaterialDifficulty = "easy" | "medium" | "hard";

export interface CourseMaterial {
  id: string;                      // e.g. "cm-algo-5-5", "cm-topic-5-7", "cm-problem-5-14"
  title: string;                   // e.g. "Algorithm 5.5: Inserting a Node After a Given Location (INSLOC)"
  book_reference: string | null;   // e.g. "Lipschutz & Seymour, Data Structures, Revised 4th Ed., Chapter 5: Linked Lists, Page 155"
  topic_tag: string | null;        // e.g. "Linked Lists", "Arrays", "Stacks", "Complexity Analysis"
  content_type: CourseMaterialContentType; // "topic" | "problem" | "algorithm"
  problem_statement: string | null;// Verbatim transcribed problem statement (for 'problem')
  explanation_or_solution: string; // Formal textbook specification, analysis, and solution in Markdown
  bangla_explanation?: string | null; // Deep, structured Bengali pedagogical walkthrough + Exam Q&A (Markdown)
  difficulty: CourseMaterialDifficulty | null; // "easy" | "medium" | "hard"
  assigned_date: string | null;    // ISO date or null
  created_by: string | null;
  created_at: string;
  updated_at: string;
}
```

## 2. Standard 5-Part Structure for Every `bangla_explanation`

Whenever creating or updating any entry (Topic, Algorithm, or Problem), the `bangla_explanation` Markdown string MUST strictly contain the following 5 structured sections:

```markdown
### 🇧🇩 সহজ বাংলায় [টপিক / অ্যালগরিদম / প্রবলেম নাম ও রেফারেন্স]

#### ১. সহজ ভাষায় মূল দর্শন ও কনসেপ্ট (Intuition & Core Concept):
- প্রাঞ্জল ভাষায় মূল উদ্দেশ্য, আইডিয়া ও যৌক্তিক ভিত্তি।
- রিয়েল-লাইফ উপমা (Real-Life Analogy): যেমন ট্রেনের বগি, লাইব্রেরির বই, ক্যাফেটেরিয়ার প্লেটের স্তূপ ইত্যাদি।
- কেন এটি প্রয়োজন এবং এর ব্যবহারিক গুরুত্ব।

---

#### ২. বিস্তারিত অ্যালগরিদম ও ড্রাই-রান / মেমরি অপারেশনস (Step-by-Step Tracing & Memory Operations):
- পয়েন্টার বা মেমরি অ্যারে রূপান্তর (\`START\`, \`AVAIL\`, \`INFO\`, \`LINK\`, \`TOP\`, \`LOC\`, \`PTR\`)।
- বাউন্ডারি ও স্পেশাল কেস বিশ্লেষণ (\`OVERFLOW\`, \`UNDERFLOW\`, খালি লিস্ট, ১টি উপাদান, সেন্টিনেল বাউন্স)।
- প্রতিটি ইটারেশনের পুঙ্খানুপুঙ্খ ড্রাই-রান টেবিল (Trace Table) বা মেমরি স্টেট।

---

#### ৩. টাইম ও স্পেস কমপ্লেক্সিটি নিখুঁত বিশ্লেষণ (Time & Space Complexity Deep Dive):
- Best Case, Worst Case, Average Case এবং Auxiliary Space Complexity এর গাণিতিক কারণসহ স্পষ্ট ব্যাখ্যা।

---

#### ৪. 🎯 পরীক্ষায় কেমন প্রশ্ন আসতে পারে? (Probable Exam Questions):
1. **সংক্ষিপ্ত প্রশ্ন (Short Questions / ২-৩ মার্কস):** সংজ্ঞা, মূল শর্ত, এজ কেস, বাউন্ডারি কন্ডিশন।
2. **রচনামূলক প্রশ্ন (Broad / ৫-১০ মার্কস):** অ্যালগরিদম লিখন, মেমরি ট্রেস টেবিল তৈরি, কমপ্লেক্সিটি প্রমাণ, অথবা তুলনামূলক পার্থক্য।

---

#### ৫. ✍️ পরীক্ষার জন্য প্রস্তুতকৃত আদর্শ উত্তর (Exam-Ready Model Answers):
- পরীক্ষায় যেভাবে লিখলে শিক্ষক সম্পূর্ণ নম্বর (Full Marks) প্রদান করবেন, সেই পয়েন্ট-বাই-পয়েন্ট কাঠামোর আদর্শ উত্তর।
```

## 3. Specific Generation Standards by Content Type

### 3.1 For Topic Entries (`content_type = 'topic'`)
- **Formal Textbook Specification**: Formal definitions, properties, memory representations (e.g., Row-Major/Column-Major for Arrays, Singly/Doubly/Circular for Linked Lists, LIFO for Stacks).
- **Complexity Summary**: Tabular breakdown of Time and Space complexity for all supported operations.
- **C++ Reference Implementation**: Clean, idiomatic modern C++ snippet illustrating the concept.
- **Deep Bengali Guide**: Rich intuition, analogies, architectural diagrams (in markdown text/tables), and full Exam Model Answers.

### 3.2 For Algorithm Entries (`content_type = 'algorithm'`)
- **Textbook Pseudocode**: Transcribe 1-indexed Lipschutz textbook pseudocode with exact variable naming (`INFO`, `LINK`, `AVAIL`, `START`, `TOP`, `LOC`).
- **Complete Boundary Guards**: Explicit `OVERFLOW` and `UNDERFLOW` checks and pointer reassignment sequences.
- **Deep Bengali Guide**: Step-by-step logic, pointer update diagrams, why the order of pointer assignments matters, and exact exam-ready algorithm write-up.

### 3.3 For Problem Entries (`content_type = 'problem'`)
- **Exact Transcription**: Verbatim problem statement from the textbook (exact input values, arrays, target keys, or expressions).
- **Step-by-Step Worked Solution**: Complete math derivation, iteration table, stack trace, or tree diagrams.
- **Deep Bengali Guide**: Plain-language walkthrough of the solution, common traps, verification checks, and model answers for semester exam questions.

## 4. Interactive Visualizer Engines (Simulation Labs)

Whenever a topic or problem benefits from visual or interactive demonstration:
1. Create or extend the corresponding visualizer in `src/components/course-material/<VisualizerName>.tsx`.
2. Register it in `src/app/course-material/page.tsx` under `VISUALIZER_REGISTRY`.
3. Support features like:
   - **Step Tracer / Playback Controls**: Step Forward, Step Back, Auto Play, Reset, and Speed sliders.
   - **Live Memory / Pointer Inspectors**: Display parallel arrays (`INFO`, `LINK`), stack tops, pointer arrows, and variable HUD counters.
   - **Preset / Custom Input Mode**: Allow preset textbook examples alongside custom user inputs.

All visualizers and markdown containers must follow AlgoHub's design system:

## 6. Implementation Workflow & Quality Verification Loop

1. **Audit & Classify**: Review input material. Classify as `topic`, `algorithm`, or `problem`.
2. **Draft Content**: Generate both English textbook specification and complete 5-part Bengali guide.
3. **Verify Exam Q&A Completeness**: Ensure the `bangla_explanation` contains BOTH `🎯 পরীক্ষায় কেমন প্রশ্ন আসতে পারে?` AND `✍️ পরীক্ষার জন্য প্রস্তুতকৃত আদর্শ উত্তর`.
4. **Compile & Typecheck**: Run `npm run build` or `npx tsc --noEmit` and ensure **0 errors**.
5. **Database Sync**: If database seeding is active, sync using `npx tsx backend/scripts/seed-course-materials.ts`.
