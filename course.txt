# AlgoHub — Course Material Feature & Content Generator Prompt
# (Lipschutz & Seymour, "Data Structures," Revised 4th Edition & Class Materials)

You are working on the existing **AlgoHub** project. Your task is to process new lecture topics, textbook algorithms, and assigned problems from *Lipschutz & Seymour, "Data Structures," 4th Edition* (provided via attached screenshot(s) or text) and integrate them seamlessly into AlgoHub's **Course Material** system.

---

## 🎯 Core Objectives & Strict Principles

1. **Self-Contained Content Generation**: Read and understand the attached screenshot(s)/text with high academic rigor and accuracy. Generate formal algorithm specifications, step-by-step traces, proofs, and comprehensive worked solutions.
2. **Pedagogical Bengali Explanations (`BanglaNote` / সহজ বাংলা ব্যাখ্যা)**: Every topic and problem must include an engaging, easy-to-understand Bengali teaching explanation (`বাংলায় সহজ ব্যাখ্যা`) that breaks down abstract concepts, intuition, edge cases, and step-by-step logic for students.
3. **Interactive Visualizer Engines (Simulation Labs)**: When a topic or problem involves step-by-step execution, pointer manipulation, memory arrays, stack operations, or complexity comparisons, provide or connect an interactive React simulation studio in `src/components/course-material/`.
4. **Flawless Light & Dark Mode UI Consistency**: Every component, visualizer, code block, math formula card, and table must look stunning and highly readable in BOTH Light Mode and Dark Mode. Never hardcode dark-only background colors (`bg-slate-900`, `bg-black`, `#14100D`) without proper light mode styling (`bg-card`, `bg-muted`, `dark:bg-...`).
5. **Preserve Existing Codebase**: Do NOT rewrite or break existing sorting algorithms, authentication flows, database schemas, or unrelated views. Only update or extend the Course Material data and component layers.

## 1. Content Modeling & Data Structure

Course materials are stored in `src/data/defaultCourseMaterials.ts` (and synced to Supabase `course_materials` table):

```typescript
export interface CourseMaterial {
  id: string;
  title: string;
  book_reference?: string;         // e.g. "Chapter 4: Linear Arrays, Section 4.3, Page 98"
  topic_tag?: string;              // e.g. "Arrays", "Linked Lists", "Stacks", "Complexity"
  content_type: 'topic' | 'problem';
  problem_statement?: string;      // Verbatim transcribed problem statement (for 'problem')
  explanation_or_solution: string; // Formal textbook specification, analysis, and solution in Markdown
  bangla_explanation?: string;     // In-depth Bengali pedagogical walkthrough (markdown supported)
  difficulty?: 'easy' | 'medium' | 'hard';
  assigned_date?: string;          // ISO date or null
  visualizer_id?: string;          // Key mapping to visualizer registry (e.g. "linear-search-studio")
}
```

---

## 2. Content Generation Standards

### 2.1 For Topic Entries (`content_type = 'topic'`)
- **Formal Specification**: Transcribe and format textbook algorithms (e.g., `Algorithm 4.3: Deleting from a Linear Array`) with 1-based textbook pseudocode, clear variable definitions, and edge cases.
- **Complexity Analysis**: Show Best Case $\mathcal{O}(1)$, Worst Case $\mathcal{O}(n)$, and Average Case $\mathcal{O}(n)$ with formal mathematical justification.
- **C++ Reference Implementation**: Clean, idiomatic modern C++ snippet illustrating the concept.
- **Bengali Intuition**: Add a comprehensive `bangla_explanation` explaining *why* the data structure/algorithm is used, how pointers or indices move, and real-life analogies.

### 2.2 For Problem Entries (`content_type = 'problem'`)
- **Exact Transcription**: Transcribe the problem statement verbatim from the screenshot (exact arrays, target values, stack operations, or permutations).
- **Step-by-Step Simulation**: Work out the complete trace step-by-step (e.g., intermediate stack contents, low/mid/high binary search comparisons, memory array `INFO` & `LINK` pointer rewiring).
- **Collapsible Solution**: Solutions must be wrapped in the interactive solution reveal deck so students can try solving first.
- **Bengali Guide**: Break down common pitfalls, why alternative answers fail, and how to verify correctness.

---

## 3. Interactive Visualizer Engines (Simulation Labs)

Whenever a topic or problem benefits from visual or interactive demonstration:
1. Create or extend the corresponding visualizer in `src/components/course-material/<VisualizerName>.tsx`.
2. Register it in `src/app/course-material/page.tsx` under `VISUALIZER_REGISTRY`.
3. Support features like:
   - **Step Tracer / Playback Controls**: Step Forward, Step Back, Auto Play, Reset, and Speed sliders.
   - **Live Memory / Pointer Inspectors**: Display parallel arrays (`INFO`, `LINK`), stack tops, pointer arrows, and variable HUD counters.
   - **Preset / Custom Input Mode**: Allow preset textbook examples alongside custom user inputs.

## 4. UI & Theming Requirements (Strict Light & Dark Mode)

All visualizers and markdown containers must follow AlgoHub's design system:

- **Outer Containers**: `rounded-3xl border border-border dark:border-cyan-500/30 bg-card dark:bg-[#080d1a]/95 text-foreground`
- **Visual Arrays / Interactive Canvas**: `bg-muted/40 dark:bg-black/40 border border-border dark:border-white/[0.08]`
- **Code Blocks & Pre tags**: `bg-muted/30 dark:bg-[#14100D] border border-border dark:border-[#382E2B] text-foreground dark:text-[#E8DFD4]`
- **Text Tokens**: `text-foreground dark:text-slate-200`, `text-muted-foreground dark:text-slate-400`
- **Accent Badges & Math Cards**: `bg-cyan-500/10 dark:bg-cyan-950/40 text-cyan-700 dark:text-cyan-300 border-cyan-500/30`
- **Bengali Note Cards**: Use `BanglaNote.tsx` (`bg-emerald-500/10 border-emerald-500/30 text-emerald-700 dark:text-emerald-400`).
