P1 ISSUES (HIGH PRIORITY / PRODUCTION SECURITY & STABILITY): 3 FOUND
--------------------------------------------------------------------------------

[P1-1] Unsandboxed Main-Thread Code Evaluation via `new Function`
  - Exact Location : src/components/practice/CodingPractice.tsx (Lines 88-90)
  - Code Snippet   :
      const userSortFnFactory = new Function(wrappedCode);
      const userSortFn = userSortFnFactory();
  - Threat Vector  :
      1. UI Thread Freeze (DoS): If a student writes an accidental infinite loop
         (e.g., `while(i < n)` without incrementing `i`), the entire browser tab
         and main JavaScript UI thread freezes permanently.
      2. Scope Access: Runs in the window's main context without DOM/global isolation.
  - Recommendation :
      Execute user-submitted algorithm code inside a dedicated Web Worker with a
      strict timeout (e.g., 1000ms execution cutoff) to automatically kill infinite loops.

[P1-2] Missing Standard Production HTTP Security Headers
  - Exact Location : next.config.ts (Lines 1-8)
  - Current State  :
      const nextConfig: NextConfig = { reactStrictMode: true };
  - Threat Vector  :
      Production deployments lack standard defense-in-depth headers:
      - X-Frame-Options: DENY (prevents clickjacking via malicious iframes).
      - X-Content-Type-Options: nosniff (prevents MIME sniffing).
      - Referrer-Policy: strict-origin-when-cross-origin (prevents referrer leak).
      - Permissions-Policy: camera=(), microphone=(), geolocation=().
      - Content-Security-Policy (CSP).
  - Recommendation :
      Add an `async headers()` configuration block in `next.config.ts`.

[P1-3] Upstream Transitive Vulnerabilities in PostCSS and Sharp
  - Exact Location : package.json (via next -> postcss and sharp)
  - Vulnerabilities:
      - postcss <=8.5.22 (High — GHSA-qx2v-qp2m-jg93, GHSA-6g55-p6wh-862q): XSS via
        unescaped style output and arbitrary source map path traversal.
      - sharp <0.35.0 (High — GHSA-f88m-g3jw-g9cj): Inherited libvips memory safety CVEs.
  - Recommendation :
      Run `npm update` or configure dependency resolutions in package.json.

P2 ISSUES (MEDIUM PRIORITY / BETA-READINESS & UX): 4 FOUND
--------------------------------------------------------------------------------

[P2-1] Missing Global Error Boundaries (`error.tsx` & `global-error.tsx`)
  - Exact Location : src/app/ (Directory Root)
  - Issue          : If an unexpected runtime rendering error occurs in any component
                     (e.g., corrupted localStorage JSON), Next.js displays an unstyled
                     generic crash screen with no retry button or navigation back home.
  - Recommendation : Create `src/app/error.tsx` with a branded error card and retry button.

[P2-2] Missing Custom 404 Route (`src/app/not-found.tsx`)
  - Exact Location : src/app/not-found.tsx (Currently non-existent)
  - Issue          : When `notFound()` is invoked or invalid algorithm slugs are visited,
                     Next.js renders its bare unstyled 404 screen.
  - Recommendation : Implement a styled `not-found.tsx` with links to `/learn` and `/`.

[P2-3] Next.js Workspace Root & Lockfile Ambiguity Warning
  - Exact Location : next.config.ts / package-lock.json
  - Issue          : Build output warning:
                     "We detected multiple lockfiles and selected the directory of
                      /Users/mushfiq/package-lock.json as the root directory."
  - Recommendation : Set `outputFileTracingRoot: path.join(__dirname, "")` in next.config.ts.

[P2-4] Missing Search Engine Directives (`robots.ts` & `sitemap.ts`)
  - Exact Location : src/app/
  - Issue          : Search engine crawlers lack sitemap indexing for the 17 documentation
                     lessons and 5 algorithm interactive pages.
  - Recommendation : Add `src/app/robots.ts` and dynamic `src/app/sitemap.ts`.
