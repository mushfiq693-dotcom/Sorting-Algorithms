1. ISSUE DESCRIPTION & UX NEED (BEFORE FIX)
================================================================================

Previous State:
  The Next.js App Router lacked a custom `not-found.tsx` component.
  When a user visited an invalid path or a dynamic route invoked `notFound()`,
  the browser displayed Next.js's default unbranded 404 page.

Risk Vectors:
  1. Broken Brand Experience: Jarring default error screen disrupted student immersion.
  2. Dead-End User Experience: Users lacked intuitive navigation buttons to return
     to the home learning journey or curriculum index.

================================================================================
2. IMPLEMENTED 404 EXPERIENCE
================================================================================

Component Created: `src/app/not-found.tsx`

Design & Features:
  - Theme Alignment: Matches AlgoHub's pitch onyx black & ruby/crimson visual identity.
  - Algorithmic Badge: `404 // ELEMENT_NOT_FOUND`
  - Algorithmic Code Hint:
      const status = routes.find(r => r.path === url);
      > return null; // [Index: -1]
  - Copy:
      Heading: "Page Not Found"
      Supporting: "The page you're looking for doesn't exist or may have been moved."
  - Two Clear Actions:
      1. Primary: "Back to AlgoHub" (Links to "/")
      2. Secondary: "Explore Learning Path" (Links to "/learn")

Accessibility & Safety:
  - Semantic `<h1>` heading hierarchy.
  - Visible focus rings (`focus-visible:ring-2 focus-visible:ring-rose-400`).
  - High-contrast text on dark surfaces.
  - Respects `prefers-reduced-motion`.
  - Zero sensitive information, file paths, or internal IDs exposed.

================================================================================
3. ROUTE BEHAVIOR & VERIFICATION
================================================================================

Case A: Direct Visit to Non-Existent URL (e.g. `/invalid-page`)
  -> Renders branded AlgoHub 404 with navigation actions.

Case B: Dynamic Algorithm Route with Invalid ID (e.g. `/algorithms/unknown-sort`)
  -> `src/app/algorithms/[algorithm]/page.tsx` calls `notFound()`.
  -> Automatically renders branded `src/app/not-found.tsx`.

Case C: Dynamic Documentation Route with Invalid Slug (e.g. `/docs/unknown-topic`)
  -> `src/app/docs/[...slug]/page.tsx` calls `notFound()`.
  -> Automatically renders branded `src/app/not-found.tsx`.
