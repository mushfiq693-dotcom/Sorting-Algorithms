     subarray recursion range is immediately obvious.

     Fuchsia Pink during merge comparisons.
   - Key Shift / Writeback: Shifting elements animated with an Orange/Write highlight.

   - CodeViewer displays verified C++17 implementations for all 5 algorithms with

   Expected Result:

C. MANUAL INTERACTIVE BROWSER TESTING:
   1. Start the dev server (if not already running):
      $ npm run dev
   
   2. Open http://localhost:3000 in your browser.
   
   3. Test each newly added algorithm:
      - [ ] Insertion Sort:
            * Select "Insertion Sort" in the Algorithms list.
            * Click "Start Sort" or "Step".
            * Notice how the current key is extracted and larger elements are 
              shifted right with an orange write badge, accurately reflecting 
              playing-card insertion.
            * Verify C++ code line 6 (while comparison) and line 7/10 (shift/insert) 
              highlight in sync.

      - [ ] Merge Sort:
            * Select "Merge Sort".
            * Click "Start Sort".
            * Notice the divide-and-conquer visual states: the left subarray is 
              highlighted in Sky Blue and the right in Fuchsia Pink during merge 
              comparisons, before writing back into the main array.
            * Verify C++ code line 5 (merge comparison) and line 10 (writeback) highlight.

      - [ ] Quick Sort:
            * Select "Quick Sort".
            * Click "Start Sort".
            * Notice the selected pivot has a distinct Purple glow with a "Pivot" badge.
            * Notice elements outside the active partition range `[low..high]` are 
              dimmed out, making recursion easy to follow.
            * Verify C++ code line 2 (pivot), line 5 (compare), line 7/10 (swap) highlight.

      - [ ] Complexity Card:
            * Select Quick Sort and verify the special recursion depth note appears
