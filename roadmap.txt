# AlgoHub — Complete Master Roadmap (Phases 1 - 8 + Beta Polish)

> **Project Architecture & Specification Document**
> Covers all sequential phases for building **AlgoHub** — an interactive algorithm learning and visualization platform
> featuring visual execution engines, step debuggers, zero-to-advanced documentation course, practice hub,
> signature infographic diagrams, deep complexity visualizations, and GSTU CSE Beta-ready landing page.

---

## GLOBAL CONTEXT

**AlgoHub** is an interactive algorithm learning and visualization platform designed to help beginners and students
understand algorithms by seeing, debugging, and practicing them.

**Tech stack:**
- Next.js 15+ (App Router)
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)
- Canvas Confetti & PrismJS

**Algorithms covered (all 5, across phases):**
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

**Non-negotiable rules:**
- Real algorithm logic only. Never hardcode or fake animation sequences — every visual step must come
  from actual execution of the algorithm, captured as a sequence of operations.
- Algorithm logic lives in pure, UI-independent TypeScript functions (`src/algorithms/*.ts`),
  each returning an array of typed operations.
- Authentic positioning: No fake statistics, fake user counts, or fake reviews.
- Restricted beta scope: Specifically tailored for Gopalganj Science and Technology University (GSTU) CSE department.

## IMPLEMENTED PHASES OVERVIEW

### PHASE 1 — Core Foundation & Visualizer Workspace (Bubble & Selection Sort)
- Pure algorithm engines exporting typed `SortOperation[]`.
- Vertical animated array bars with state color-coding.
- Playback controls (Start, Pause, Resume, Step, Reset), Speed/Size sliders, Custom array input.
- Line-by-line synchronized C++ code viewer.

### PHASE 2 — Expanding Algorithm Engines (Insertion, Merge, Quick Sort)
- Insertion Sort: Key extraction and shifting.
- Merge Sort: Divide & Conquer subarray ranges, left/right merge comparisons, array overwrite.
- Quick Sort: Lomuto partitioning, pivot glow, active subarray range dimming.
- 5-algorithm selector and Big-O complexity card.

### PHASE 3 — Comparison Matrix & Polish
- Comparison matrix page (`/compare`) with 8 evaluation criteria and practical engineering guidance.
- Hero sorting animation, responsive layout, visible keyboard focus states, `prefers-reduced-motion`.

### PHASE 4 — Beginner Learning Path, Code Debugger & Bug-Hunt Challenge
- Guided pedagogical curriculum (`/learn`) with time estimates and completion checks.
- Step-by-step C++ Code Debugger with live variable inspector and recursive call stack.
- Interactive Bug-Hunt Challenge with real flawed algorithm engines and in-line fix verification.

### PHASE 5 — Full Documentation (Zero → Advanced) + Bangla Notes + Practice Modes
- 17 course lessons across 5 levels (`/docs`) covering definitions, recursion, and formal Big-O proofs.
- Collapsible `"বাংলায় বুঝি 🇧🇩"` callout notes for hard concepts.
- 3 new practice modes: Quiz Mode, Prediction Exercises, and TypeScript Coding Practice.

### PHASE 6 — Full UI Polish (Dark Dev-Tool Aesthetic + Micro-Interactions)
- Palette strictly derived from visualizer states (Cyan, Amber, Rose, Emerald, Violet) on Obsidian (`#050811`).
- Ambient Sort Logo: Live 5-bar micro-sorting engine in header.
- Compare hover shimmers, card swap transitions, and sorted settlement waves.

### PHASE 7 — Signature Static Diagrams ("The Full Picture" / At a Glance)
- Static, infographic-style, non-animated, screenshot-ready reference diagrams for every algorithm.
- Merge Sort recursion tree, Quick Sort asymmetric partition tree, Bubble Sort pass timeline, Selection Sort moving split, Insertion Sort shift zone.

### PHASE 8 — Deep Complexity Visualization: Math Derivations, Interactive Calculator, Growth Graphs
- Mathematical Derivations (`MathDerivation.tsx`): Step-by-step arithmetic series expansions and proofs.
- Interactive Big-O Calculator (`ComplexityCalculator.tsx`): Single & cross-algorithm predicted counts.
- Growth Rate Comparison Graph (`GrowthChart.tsx`): Zoomable curves for $O(1), O(\log n), O(n), O(n \log n), O(n^2)$.
- Live Operation Counter & Post-Run Diagnostics (`LiveComplexityTracker.tsx`): Real-time tracking vs theoretical bounds.

### BETA POLISH — Product Positioning & Landing Page Upgrade (AlgoHub Rebrand)
- Complete global rebrand from SortViz to **AlgoHub**.
- Hero headline *"Algorithms, Visualized."* and tagline *"Don't just learn Algorithms. See them. Break them. Fix them. Master them."*
- 4-Stage Learning Journey: `01 LEARN` $\to$ `02 VISUALIZE` $\to$ `03 DEBUG` $\to$ `04 PRACTICE`.
- Outcome-focused value proposition cards and 5-algorithm curriculum showcase.
- Department-restricted beta positioning for GSTU CSE students with active feedback & bug report channels.
