**C++ reference implementations to embed (use exactly these, they're already verified correct):**

```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

```cpp
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}
```

## PHASE 2 — Add Insertion, Merge, Quick Sort

**Prerequisite:** Phase 1 is verified working. Reuse all existing architecture — do not rebuild
the visualizer, controls, or state management.

Build:

1. **Insertion Sort engine + explanation:**
   - Mechanism to convey in the explanation panel: like arranging playing cards — take the next
     unsorted element (the "key") and shift sorted elements right until the correct slot is found.
   - Visualizer must distinguish: sorted portion, current key, elements actively shifting.
   - Animate as an actual shift (element moving to a new slot), not a generic swap — this matters
     for accuracy.

   ```cpp
   void insertionSort(vector<int>& arr) {
       int n = arr.size();
       for (int i = 1; i < n; i++) {
           int key = arr[i];
           int j = i - 1;
           while (j >= 0 && arr[j] > key) {
               arr[j + 1] = arr[j];
               j--;
           }
           arr[j + 1] = key;
       }
   }
   ```

2. **Merge Sort engine + explanation:**
   - This needs `merge-start` and `merge-compare` operations (already defined in the shared type)
     to represent divide-and-conquer correctly — don't reduce it to plain compare/swap, that would
     misrepresent the algorithm.
   - Visualizer must show: the array splitting into subarrays (divide phase), then during merge:
     left subarray highlighted, right subarray highlighted, which element is currently being
     compared/selected, and the merged result being written back.
   - A simple division diagram (even static, per the example below) helps beginners — include one
     in the explanation panel for this algorithm specifically.

   ```cpp
   void merge(vector<int>& arr, int left, int mid, int right) {
       vector<int> temp;
       int i = left, j = mid + 1;
       while (i <= mid && j <= right) {
           if (arr[i] <= arr[j]) temp.push_back(arr[i++]);
           else temp.push_back(arr[j++]);
       }
       while (i <= mid) temp.push_back(arr[i++]);
       while (j <= right) temp.push_back(arr[j++]);
       for (int k = left; k <= right; k++) arr[k] = temp[k - left];
   }

   void mergeSort(vector<int>& arr, int left, int right) {
       if (left >= right) return;
       int mid = left + (right - left) / 2;
       mergeSort(arr, left, mid);
       mergeSort(arr, mid + 1, right);
       merge(arr, left, mid, right);
   }
   ```

3. **Quick Sort engine + explanation:**
   - Use the `pivot` and `range` operations to clearly mark the pivot element and the active
     partition range during recursion.
   - Visualizer must show: pivot clearly marked (distinct color), the active subarray range dimmed
     differently from the rest of the array, partitioning happening in place.
   - Skip the recursion tree diagram for now (that's Phase 3, optional) — focus on correctness and
     clarity of the partition step itself.

   ```cpp
   int partition(vector<int>& arr, int low, int high) {
       int pivot = arr[high];
       int i = low - 1;
       for (int j = low; j < high; j++) {
           if (arr[j] < pivot) {
               i++;
               swap(arr[i], arr[j]);
           }
       }
       swap(arr[i + 1], arr[high]);
       return i + 1;
   }

   void quickSort(vector<int>& arr, int low, int high) {
       if (low < high) {
           int pi = partition(arr, low, high);
           quickSort(arr, low, pi - 1);
           quickSort(arr, pi + 1, high);
       }
   }
   ```

4. **Update algorithm selector** — now lists all 5 algorithms.

5. **Complexity table for all 5** (can now build the shared reference table):

   | Algorithm | Best | Average | Worst | Space | Stable |
   |---|---|---|---|---|---|
   | Bubble | O(n) | O(n²) | O(n²) | O(1) | Yes |
   | Selection | O(n²) | O(n²) | O(n²) | O(1) | No |
   | Insertion | O(n) | O(n²) | O(n²) | O(1) | Yes |
   | Merge | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes |
   | Quick | O(n log n) | O(n log n) | O(n²) | O(log n)* | No |

   *Quick Sort space note: O(log n) average recursion depth, degrades to O(n) worst case on
   already-sorted input with poor pivot choice — mention this explicitly in the UI.
