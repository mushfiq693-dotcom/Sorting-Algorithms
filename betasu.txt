1. PRODUCT OVERVIEW & CORE PHILOSOPHY
================================================================================

AlgoHub (rebranded from SortViz) is an interactive, portfolio-grade educational 
web platform designed to transform how students and beginners learn Data 
Structures and Algorithms (DSA). 

Instead of treating algorithms as static textbook pages or passive animations, 
AlgoHub provides an active sandbox where learners can:
  * SEE algorithms execute step by step in real time.
  * BREAK algorithm implementations with live boundary conditions.
  * FIX buggy code in hands-on debugging challenges.
  * MASTER mathematical proofs, asymptotic curves, and practical trade-offs.

CORE SLOGAN & POSITIONING:
  Headline: "Make Algorithms Make Sense."
  Tagline: "Don't just learn Algorithms. See them. Break them. Fix them. Master them."
  Scope: Gopalganj Science and Technology University (GSTU) CSE Department Beta.

3. COMPLETE FEATURE BREAKDOWN (BY IMPLEMENTED PHASES)
================================================================================

--------------------------------------------------------------------------------
PHASE 1: Core Foundation & Visualizer Workspace
--------------------------------------------------------------------------------
- Real-Time Array Bars: Vertical animated bars with dynamic height percentage 
  and real-time color transitions based on execution state.
- Full Playback Engine: Start, Pause, Resume, Step Forward, and Reset controls.
- Interactive Sliders: Dynamic Animation Speed (20ms - 500ms) and Array Size (5 - 50).
- Custom Array Input: Modal allowing custom comma-separated numeric sequences.
- Line-by-Line Synchronized C++ Viewer: Highlights the exact C++ line of code 
  corresponding to the current visualizer step.

--------------------------------------------------------------------------------
PHASE 2: Full 5 Sorting Algorithm Engines
--------------------------------------------------------------------------------
- Bubble Sort: Adjacent pairwise comparisons, bubbling swaps, and sorted boundary.
- Selection Sort: Minimum element scanner, global tracking, and locked sorted prefix.
- Insertion Sort: Key extraction, backward shifting chain, and target insertion.
- Merge Sort: Divide & Conquer recursion ranges, subarray split, left/right merge, 
  and auxiliary-to-main array overwrite.
- Quick Sort: Lomuto partitioning, pivot glow, active subarray range dimming.
- Live Telemetry: Active comparisons counter, swap counter, array access tracker.

--------------------------------------------------------------------------------
PHASE 3: Multi-Dimensional Comparison Matrix (/compare)
--------------------------------------------------------------------------------
- Full Matrix Table: Compares all 5 algorithms across Best/Average/Worst Time, 
  Auxiliary Space, Stability, In-Place behavior, and Method.
- Practical Engineering Guidance: "When to use", "When to avoid", and real-world 
  library implementations (e.g., Timsort, std::sort / Introsort, glibc qsort).

--------------------------------------------------------------------------------
PHASE 4: Structured Learning Path, Code Debugger & Bug-Hunt Challenge (/learn)
--------------------------------------------------------------------------------
- 5-Stage Guided Curriculum: Progressive learning path (Bubble -> Selection -> 
  Insertion -> Merge -> Quick Sort) with estimated times and progress checkmarks.
- Step-by-Step C++ Debugger: Allows line-by-line stepping with live Scope Variable 
  Inspector (i, j, key, min_idx, pivot) and recursive Call Stack frames.
- Interactive Bug-Hunt Challenges: Real flawed algorithm engines with intentional 
  bugs (e.g., off-by-one errors, missing swap flags, wrong partition conditions)
