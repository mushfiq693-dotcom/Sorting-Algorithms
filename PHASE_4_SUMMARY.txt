[1] KI KI KORA HOYECHE (WHAT WAS BUILT IN PHASE 4)
--------------------------------------------------------------------------------
1. PART A — Beginner Learning Path & Progressive Disclosure:
   - Learning Path Page (src/app/learn/page.tsx):
     * Sequenced pedagogical roadmap: 1. Bubble -> 2. Selection -> 3. Insertion -> 
       4. Merge -> 5. Quick Sort.
     * Shows estimated completion times, "why this order" rationale, analogies, and 
       in-session completion progress tracker.
   - Per-Algorithm Deep Dive Pages (src/app/algorithms/[algorithm]/page.tsx):
     * 5-step progressive disclosure stepper: 
       1. The Idea (Plain English & honest analogies)
       2. Watch It Work (pre-loaded small ~8 element visualizer)
       3. Read the Code (annotated logical block dissections)
       4. Why It's Fast/Slow (complexity rationale)
       5. Try It (interactive practice with Debugger and Bug-Hunt)
   - Terminology Glossary Modal (src/components/glossary/GlossaryModal.tsx):
     * 12 core DSA terms (comparison, swap, in-place, stable, recursion, pivot, 
       partition, etc.) with non-circular plain definitions, search, and category filters.

2. PART B — Step-by-Step Code Debugger:
   - Component: src/components/debugger/CodeDebugger.tsx
   - Features:
     * Synchronized C++ code viewer with active line tracking.
     * Live Variables Inspector: dynamically shows in-scope values (i, j, minIdx, 
       key, pivot, swapped, n, array snapshot).
     * Call Stack Panel for recursive algorithms (Merge Sort & Quick Sort) showing 
       nested activation records and unwinding.
     * Controls: Step Into (forward), Step Back (time-travel backwards without 
       re-running), Run, and Reset.
     * Contextual Plain-English execution explanations referencing live values.

3. PART C — Bug-Hunt Challenge:
   - Component: src/components/challenge/BugHunt.tsx
   - Features:
     * Pre-written realistic flawed C++ code for all 5 algorithms.
     * Real flawed algorithm engines in src/algorithms/buggy/* that genuinely 
       produce authentic wrong sorting visuals.
     * Interactive line selection: Click a line in the code viewer to edit.
     * Inline fix validation and instant visual verification.
     * Hints and explanations for why the bug occurred and why the fix works.
