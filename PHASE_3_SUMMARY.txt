   $ npm run test:algorithms

   Run:
   $ npm run build
   
   Expected Result:
   - 5/5 static pages generate cleanly with 0 TypeScript/Lint errors.

C. MANUAL INTERACTIVE BROWSER TESTING:
   1. Start the development server (if not already running):
      $ npm run dev
   
   2. Open http://localhost:3000 in your browser:
      - [ ] Hero Section: Observe the looping mini sorting animation in the hero card.
      - [ ] Comparison Link: Click "Compare All 5 Algorithms" in the hero or 
            "Compare Matrix" in the top navbar.
      - [ ] Comparison Matrix Page (/compare):
            * Review the side-by-side comparison table for Bubble, Selection, 
              Insertion, Merge, and Quick Sort.
            * Review the "Which Algorithm Should I Use?" practical guidance cards.
            * Click "Back to Visualizer" to return to the home workspace.
      - [ ] Keyboard Navigation: Use the `Tab` key on your keyboard to navigate 
            through Start Sort, Pause, Resume, Step, Reset, Sliders, and Custom Array. 
            Notice the clear cyan focus rings.
      - [ ] Responsive Layout: Resize your browser window or open DevTools mobile view 
            (375px width) to confirm seamless stacking and readable controls.
