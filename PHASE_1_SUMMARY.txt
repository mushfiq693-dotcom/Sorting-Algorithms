[1] KI KI KORA HOYECHE (WHAT WAS BUILT IN PHASE 1)
--------------------------------------------------------------------------------
1. Project Setup:
   - Next.js 15+ App Router, React 19, TypeScript, Tailwind CSS, Framer Motion, 
     Lucide Icons, and Canvas Confetti setup.

2. Pure Algorithm Engines (Zero UI Dependencies):
   - src/algorithms/bubbleSort.ts: Real Bubble Sort with early break optimization,
     returning typed SortOperation[].
   - src/algorithms/selectionSort.ts: Real Selection Sort scanning minIdx and 
     swapping, returning typed SortOperation[].

3. Interactive Visualizer Components:
   - ArrayBars.tsx: Smooth animated vertical bars with dynamic color states 
     (Default Blue/Cyan, Comparing Amber/Yellow, Swapping Red/Rose, Sorted Emerald/Green).
   - VisualizerControls.tsx: Full playback controls (Start, Pause, Resume, Step Forward,
     Reset), Speed Slider (20ms–800ms), Array Size Slider (5–50), Random Generator, 
     and Custom Array input with robust validation.
   - OperationIndicator.tsx: Real-time dynamic explanation text, live counters for 
     Comparisons, Swaps, and Step progress.
   - CodeViewer.tsx: C++17 implementation viewer with copy-to-clipboard button and 
     synchronized line-by-line execution highlighting.
   - AlgorithmSelector.tsx: Clean selection list for Bubble Sort and Selection Sort.
   - ComplexityCard.tsx: Detailed Best/Average/Worst Time, Space, Stability, and 
     In-Place properties card.
   - Landing Page (src/app/page.tsx): Modern dark-themed hero section with 
     headline, subheading, CTA button, and workspace.

[2] KIVABE TEST KORBEN (HOW TO TEST & VERIFY)
--------------------------------------------------------------------------------

A. AUTOMATED TEST SUITE (Unit Testing):
   Run the following command in your terminal:
   $ npm run test:algorithms
   
   Expected Result: 
   - 12/12 tests will pass covering: Random array, Already sorted array, 
     Reverse sorted array, Array with duplicates, Single element array, and Empty array.

B. PRODUCTION BUILD TEST:
   Run:
   $ npm run build
   
   Expected Result:
   - Compiled successfully with 0 TypeScript/Lint errors.

C. MANUAL INTERACTIVE BROWSER TESTING:
   1. Start the development server:
      $ npm run dev
   
   2. Open http://localhost:3000 in your browser.
   
   3. Test the following features:
      - [ ] Start / Pause / Resume: Click "Start Sort", observe the bars animating 
            and C++ code lines highlighting. Click "Pause" to freeze execution, then 
            click "Resume" to continue without skipping or restarting.
      - [ ] Step Forward: Click "Step" repeatedly while idle or paused to execute 
            exactly one operation per click.
      - [ ] Reset: Click "Reset" to return the array and statistics to the pre-sort state.
      - [ ] Speed Slider: Move the slider between Fast (20ms) and Slow (800ms) to 
            observe animation speed changes.
      - [ ] Array Size Slider: Change bar count (5 to 50 bars) and click Random Array.
      - [ ] Custom Array Input:
            * Enter valid numbers: `45, 12, 89, 34, 7` and click "Apply".
            * Test validation: Enter letters like `abc` or numbers > 500 to verify 
              inline error handling.
      - [ ] Code Viewer Synchronization: Observe how the active line in C++ code 
            highlights line 6 (compare) and line 7/8 (swap) in real-time. Click "Copy" 
            to test clipboard copy.
      - [ ] Algorithm Switch: Switch between "Bubble Sort" and "Selection Sort" 
            and verify that complexity metrics and C++ code update immediately.
